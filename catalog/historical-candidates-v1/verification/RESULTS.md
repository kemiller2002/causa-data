## Known limitation

The existing catalog manifest schema permits exactly the established three historical case keys, while the frozen active
demonstration catalog permits exactly four total investigations. The candidates therefore validate as ordinary Causa
investigation directories through the common import/storage mechanism, but cannot be inserted into the active catalog
without an explicit post-kickoff requirement and schema change. No special-case code was added.
