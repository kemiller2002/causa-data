# Historical candidates v1

This directory contains provenance and verification records for two import-ready, data-only Causa investigations. The
investigation files are under `workspaces/demo/historical-candidates-v1/investigations/`; source manifests and claim-level
research are under `research/historical/`.

This is intentionally **not** an active catalog manifest. The current catalog schema and frozen competition requirement
permit only the established four-case demonstration catalog. See `docs/HISTORICAL-CANDIDATES-V1.md` for the limitation,
case descriptions, import paths, and demonstration recommendation.
